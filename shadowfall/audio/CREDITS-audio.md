# Audio credits

Every sound in Shadowfall is made in code by `audio/synth.gd` from the tunes in `audio/tunes.gd` and the
recipes in `audio/sfx.gd`. No samples, no downloads, no third-party audio: there is nothing to credit yet.

The rule (docs/teen/audio/README.md §3): an audio file may enter the repo only if (a) a script in the repo
makes it, (b) a tracker source file we wrote sits next to it, or (c) it is CC0 and has a line below with its
URL and licence.
